Unity Job System 是引擎自带的 C# 并行任务，用来把大量纯计算拆到多核，常和 Burst（把作业编译成很快的原生代码）一起用。

和 `Task.Run` 的差别：

|     | Task.Run            | Job System                                          |
| --- | ------------------- | --------------------------------------------------- |
| 谁提供 | .NET 线程池            | Unity 自己的作业调度                                       |
| 典型活 | 一块不好拆的后台计算          | 几千上万次相同的数学（粒子、变换、网格）                                |
| 限制  | 不能碰 Unity 对象        | 更严：Burst 下基本不能用普通 `class` / `string` / `GameObject` |
| 数据  | 随便用托管对象（只要不碰引擎）     | 多用 `NativeArray` 这类非托管容器                            |
| 怎么开 | Task.Run(() => ...) | 主线程 `job.Schedule()`，之后 `Complete()` 或等依赖           |
