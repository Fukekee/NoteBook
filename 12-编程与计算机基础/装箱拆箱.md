值类型被当成 `object` / 进[^1]非泛型容器。`Update` 里一装箱就掉帧。
`int`、`float`、`Vector3`、`bool` 是值类型：数字本身就在变量里，通常跟着栈或嵌在别的对象里，没有单独再 `new` 一个堆对象。

`object`、以及所有 `class`，是引用类型：变量里只有门牌号，本体在堆上。

装箱发生在：一个值类型，被塞进「只收引用」的洞里。运行时只好：

1. 在堆上新开一个盒子
2. 把这个数拷进去
3. 把门牌号交给那个洞

`int hp = 10; // 值，没有堆对象`

`object box = hp; // 装箱：堆上多了一个装着 10 的盒子`

`int hp2 = (int)box; // 拆箱：从盒子里再拷回一个 int`

`hp` 和盒子里的 10 是两份拷贝。改 `hp` 不会改盒子。

每帧装箱 → 堆上多垃圾 → GC 偶尔卡一下。所以才说「`Update` 里别乱装箱」。

**没装箱的写法： 用泛型、用 `ToString()` 自己拼、或干脆别每帧打日志。**

[^1]: 容器 = 列表、字典这种装东西的口袋。
	
	泛型容器把「里面是哪种类型」写死。非泛型容器是 C# 很早的旧口袋，口子类型是 `object`（任意对象）代码中基本不会出现
