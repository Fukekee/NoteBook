## 什么情况下才“只加载需要的、不需要的不进内存”

如果你的目标是大场景省内存（只让附近的进内存，远的不进/卸载），那要用主动的资源管理方案，Unity 不会自动帮你做：

| 方案                      | 作用                                                                             |
| ----------------------- | ------------------------------------------------------------------------------ |
| 场景分块 + 多场景加载            | 用 `SceneManager.LoadSceneAsync(Additive)` / `UnloadSceneAsync`，玩家走到哪加载哪块，离开就卸载 |
| Addressables            | 按需异步加载/释放资源，用引用计数管理内存，是目前官方推荐的大世界方案                                            |
| 流式加载 Streaming          | 自己写距离判断，动态 Instantiate / Destroy 或对象池                                          |
| Terrain / Tree / Detail | 地形系统有自己的 LOD 和分块加载机制                                                           |
| LOD Group               | 注意：LOD 只切换渲染用哪级模型，所有 LOD 级别的 Mesh 默认还是都在内存                                     |
