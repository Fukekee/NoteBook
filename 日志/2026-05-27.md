# Editor 内 main 场景无法点击 UI 排查记录

环境：Unity 6000.3.5f2 + Input System 1.17.0，Windows，单机调试  
影响范围：仅本机 Editor，仅 `Assets/Scenes/main.unity` 场景；真机正常、同事电脑正常、其它场景（`MainUIcopy`、空场景）正常

---

## 1. 现象

1. 在 Editor Play `main` 场景后，所有 UI 按钮点击无效（悬停不变色，`onClick` 不触发）。
2. `PlatformUIManager` 动态创建的 LogoLockupImage 动画也不播放。
3. 真机正常；同事在自己电脑上 Play 同一份 main 场景正常。
4. 删除场景里任意一部分对象（不是某个特定对象）后，按钮能点了、动画也能播了。
5. Console 报错示例：
    
    ArgumentOutOfRangeException: Specified argument was out of the range of valid values.
    
    Parameter name: key: 256
    
    堆栈定位到 `Assets/Scripts/PlayerConnect/Location/LocationDebugUI.cs:81`。

---

## 2. 根因

`Assets/Scenes/main.unity` 中的 `LocationDebugUI` 组件，序列化字段值非法：

m_EditorClassIdentifier: Assembly-CSharp::LocationDebugUI

showInBuild: 0

toggleKey: 256 # ← 越界，UnityEngine.InputSystem.Key 枚举无 256

`LocationDebugUI.Update()` 每帧执行：

void Update()

{

var keyboard = Keyboard.current;

if (keyboard != null && keyboard[toggleKey].wasPressedThisFrame) // ← 抛

ToggleVisibility();

...

}

`Keyboard` 索引器内部访问 `m_Keys[(int)toggleKey]` → `ArgumentOutOfRangeException`，每帧抛一次。

在 Unity Editor 中，每帧抛异常 + 写 Console + Console 窗口重绘 + Editor.log 落盘 的开销极大（单次可达几十毫秒）。叠加 `main` 场景本身的复杂度（约 75 万行 YAML、Mapbox/NetCode/AR 等系统初始化），导致：

- Editor 主线程帧时间长到接近停滞
- 鼠标点击事件落在两帧之间被吞掉
- 动画、UI 渲染几乎不更新
- 表现上像是「按钮坏了 / EventSystem 不工作」
