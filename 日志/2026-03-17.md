## 完整的联机位置驱动链路
【客户端 - 本机玩家】
  Amap GPS 更新
    → LocationManager.OnLocationUpdated
      → LocationToWorldAdapter.OnLocationUpdated
          → _targetTransform.position = worldPos   ← target 被更新
              ↓
  GpsTargetSyncProxy.Update() 读 target.position
    → 位移 ≥ 0.5m 时 → RequestSyncGpsOffset(pos)
        → RPC_ClientSyncGpsOffset 发往服务器
              ↓
【服务器 - StateAuthority】
  RPC_ClientSyncGpsOffset 收到
    → GpsOffset = offset（网络属性）
    → UpdateTargetPosition(offset)   ← 服务器侧该玩家的 target 也更新
    → 打印 "[PlayerSetup] RPC_ClientSyncGpsOffset (SA) applied..."
              ↓
【所有设备 - Fusion 自动广播 GpsOffset】
              ↓
【其他玩家设备 - 远端】
  Render() 检测到 GpsOffset 变化
    → UpdateTargetPosition(GpsOffset)  ← 远端设备上该玩家的 target 更新
      → CharacterMovement 追踪 target → 玩家在屏幕上移动
