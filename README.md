# NoteBook

个人 Unity / C# 学习笔记库，同时也是一个 [Obsidian](https://obsidian.md) Vault。

内容主要来自日常开发中踩过的坑和查过的资料，覆盖 Unity 引擎、动画系统、UGUI、渲染、物理、AR 与地图定位、多人联机、性能优化，以及 C# 和计算机基础。

## 使用方式

```bash
git clone https://github.com/Fukekee/NoteBook.git
```

用 Obsidian 的「打开文件夹作为仓库」选中克隆下来的目录即可。`.obsidian/` 里已包含配置，图形视图、双链、Canvas 等功能开箱可用。

只想读内容的话，直接在 GitHub 上浏览 Markdown 也可以，只是 `[[双链]]` 不会渲染成可点击链接。

## 记录约定

**笔记流转**：临时想法和当天的排查过程先写进 `00-日志`，沉淀成通用知识点后再整理到对应主题目录。

**内部链接**统一用不带路径的 wikilink（`[[生命周期]]`）。Obsidian 按文件名解析，这样挪动文件不会断链，代价是**全库笔记不能重名**。

**图片**统一放 `Pic/`，通过 `![[Pasted image xxx.png]]` 引用。Obsidian 的附件目录已配置为该文件夹，粘贴截图会自动存入。

**标记习惯**：`==高亮==` 表示重点结论，`%% %%` 是不对外显示的补充注释。

## 说明

这是个人向的学习记录，写给自己看，因此会有大量结论式的短句、未完成的片段和项目专属的上下文。内容基于 Unity 6.x / URP，部分结论仅在特定版本或特定项目环境下验证过，引用前建议自行核实。
