## 生命周期（引擎会自动调的函数）

按常见执行顺序：

|函数|什么时候|典型用途|
|---|---|---|
|`Awake`|物体第一次被加载，且组件存在时|拿引用、初始化自己，不依赖别的脚本已经 `Start`|
|`OnEnable`|组件被启用时（含第一次）|订阅事件、开始监听|
|`Start`|第一次 `Update` 之前，且组件启用|依赖其他脚本已经 `Awake` 完的初始化|
|`Update`|每帧|输入、UI、非物理逻辑|
|`FixedUpdate`|固定时间步（默认约 0.02s）|刚体、物理相关|
|`LateUpdate`|所有 `Update` 之后每帧|摄像机跟随，避免抖|
|`OnDisable`|组件被禁用或物体销毁前|取消订阅|
|`OnDestroy`|物体/组件销毁时|收尾、释放|

启用物体时大致是：

Awake → OnEnable → Start → (循环) Update / FixedUpdate / LateUpdate[[各种Update]]

禁用：OnDisable

销毁：OnDisable → OnDestroy

注意：

- 物体一开始是 inactive，`Awake`/`Start` 会推迟到它被激活
- 组件被关掉再打开：会再走 `OnEnable`，不会再走 `Awake`/`Start`
- `Update` 系列在组件 disabled 时不会跑
