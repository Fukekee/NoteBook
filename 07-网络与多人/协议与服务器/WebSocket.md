WebSocket 是一种网络协议：先用 HTTP 握手，然后升级成一条长连接，双方随时互相推消息。

对比：

|      | HTTP 请求       | WebSocket       |     |
| ---- | ------------- | --------------- | --- |
| 寿命   | 问一句、答一句，连接常关掉 | 连上就一直开着         |     |
| 方向   | 基本是客户端先问      | 两边都能主动推         |     |
| 典型用途 | 拉一次配置、登录、REST | 房间状态、聊天、匹配、实时通知 |     |


你们用的 UOS 房间服务那套（建房、`roomCode`、房间状态）就是这类长连接：大厅/房间服务随时可能推「有人加入」「房间没了」，客户端挂着 WebSocket 收推送，而不是每 200ms 轮询一次 HTTP。

和 NGO 的 RPC 也不一样：

- WebSocket（UOS）：和房间/账号后端说话——建房、进房、房间列表。
- NGO RPC：已经进了同一局游戏之后，玩家和主机之间的玩法指令——黑屏、抢分、原点同步。

两条都是网络 IO，跑在不同连接上。
