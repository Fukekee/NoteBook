让一个物体"永远渲染在最上层"在 Unity 里有几种主流做法，从简单到复杂排开，按你的场景需求选。

## 方法 1：自定义 Shader 关掉深度测试（最常用）

写一个 Shader，把 `ZTest Always` 打开、`Queue` 调到 `Overlay` 或者更高，渲染时直接覆盖 ZBuffer 的判定。

### URP 版（你项目是 URP）

新建一个 Shader Graph 或 Unlit Shader，在 SubShader 里加：

Tags { "RenderType"="Opaque" "Queue"="Overlay+1" "RenderPipeline"="UniversalPipeline" }

Pass

{

ZTest Always // 关键：永远通过深度测试

ZWrite Off // 一般也关掉，避免影响后面其他物体

Cull Back

...

}

`ZTest Always` 让 GPU 在深度测试这一步永远判 true，所以物体永远画上去。

`Queue = Overlay+1`（数值上 = 4001+）让它在所有半透明物体之后绘制，确保覆盖。

> Shader Graph 的话：Universal → Unlit → Graph Settings 里把 `Render Face` / `Depth Test` 设为 `Always`，`Depth Write` 设为 `Off`，`Surface Type` 选 `Opaque` 或 `Transparent` 都行。


优点：开销小，是真正"画在最后、压过所有像素"。 缺点：物体内部前后两面也会互相穿（因为深度测试都关了），所以这个方案**对"凸的、单层"的物体最理想**；如果是有内部结构的复杂模型，需要走方法 2。

## 方法 2：用第二个相机 + 独立 Layer 叠加渲染

这是 FPS 游戏里"枪不会插墙"那种效果的标准做法。

步骤：

1. 新建一个 Layer，比如 `AlwaysOnTop`，把目标物体的 Layer 设成它。
2. 主相机的 `Culling Mask` 把 `AlwaysOnTop` 关掉（让主相机不画它）。
3. 新建一个相机（叫 `OverlayCam`），它的 `Culling Mask` 只勾 `AlwaysOnTop`。
4. URP 下，把这个 OverlayCam 的 `Render Type` 设为 Overlay，然后在主相机的 `Stack` 里把 OverlayCam 加进去。
5. OverlayCam 的 `Clear Flags`：`Don't Care` 或者只清深度（`Clear Depth`），不要清颜色——这样它会在主相机画完之后接着画。
6. OverlayCam 一般和主相机参数完全相同（Position / FOV / Projection），可以挂个脚本同步：
    
    transform.position = mainCam.transform.position;
    
    transform.rotation = mainCam.transform.rotation;
    
    或者==直接把 OverlayCam 设为 mainCam 的子物体==。

优点：物体内部的深度关系还是正确的（因为 OverlayCam 自己的 Pass 里深度测试照常工作），只是相对于主场景永远在最上层。 缺点：多一个 Camera，移动端有一点点性能成本；URP 必须用 Camera Stack。

这是复杂模型 + 永不穿模的最佳方案。
