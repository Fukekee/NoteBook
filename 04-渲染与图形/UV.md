UV是四边都是0~1范围的正方形

**UV Channel**
uv0:常用来做贴图
uv1:常用来做lightMap,做光照图，实现没有实时光影响下的模型本身自带着的阴影和高亮

**模型的UV展开**
3d模型的所有三角面在一张方形图上展开后，就做好了该模型的UV展开图，后续给这个模型贴图就靠贴图上的像素与UV展开图对应而来，
值得一提的是，模型上的每个三角面贴在UV上后，它们之间的比例不是一定要保留原本的比例的，如果想让模型部分区域的贴图更清晰，更细节，那么就压缩其他三角面的UV投射比例。

## UV 是什么？0～1 代表什么？

UV 是「网格表面上的点 → 纹理上的哪个像素」的映射。

- U = 0：纹理左边缘
- U = 1：纹理右边缘
- V = 0 / 1：下 / 上边缘

UV 在 0～1 内 = 整张图只铺一遍。
## 为什么会出现 UV 超出 0～1？

常见有几类：

### 1. 故意平铺（最常见，尤其是 3D）

材质里可以设 Tiling（平铺次数），例如地砖：

Tiling = (5, 5)

Shader 里实际采样大致是：

采样 UV = 网格 UV × Tiling

网格 UV 从 0 到 1，乘完就变成 0～5，大量采样点落在 0～1 外面。

这时需要 Repeat：3.7 折回 0.7，看起来像贴了 5×5 块砖，而不是一块砖被拉很大。

Repeat: ... | 0.7 | 0.8 | 0.9 | 0.0 | 0.1 | ...

同一块砖在重复

Clamp: ... | 0.7 | 0.8 | 0.9 | 1.0 | 1.0 | 1.0 | ...

超出 1 以后全是右边缘像素 → 一条色带

### 2. 建模时 UV 就铺了好几遍

在 Blender/Maya 里，一块大地面的 UV 可以直接画成 0～10，意思也是「重复 10 次」，效果和 Tiling 类似。

### 3. Shader 自己算 UV

例如：

- 滚动水面：`uv + time` 会一直增大
- 世界坐标当 UV：`worldPos.xz * 0.5` 随场景变大可以到几十、几百
- 三平面映射、程序纹理等

这些都会让采样坐标经常超出 0～1。

### 4. 过滤时「轻微越界」（UI 也会遇到）

即使逻辑 UV 在 0～1 内，双线性过滤会在边缘多采一点相邻像素。  
图集里两张图挨着时，就可能采到隔壁图 → 就是sprite的 Extrude Edges 要解决的问题。

## 那 0～1 到底意味着什么？

更准确的说法是：

> UV 坐标差值为 1 → 在面上对应贴图的一个完整宽高周期。

不是「UV 必须落在 [0,1] 区间」。

类比：

- 米制里「1 米」是单位
- 房间长 5 米，不是说长度不能超过 1
- UV 里 1 是「一张贴图」的单位
- 面上可以是 5 张贴图 → UV 跨度就是 5

## 从 Mesh 到最终采样的链路

实际采样时往往分两步：

① Mesh 顶点 UV（建模 / 导入时就有）

↓

② Shader 里常再变换：finalUV = meshUV × Tiling + Offset

↓

③ 用 finalUV 去采纹理，Wrap Mode 作用在这一步

所以「超出 0～1」可能来自：

|来源|例子|
|---|---|
|Mesh UV 本身就 > 1|地面 UV 直接画成 0～10|
|Mesh UV 是 0～1，但 Tiling > 1|`Tiling = (5,5)` → 采样时变成 0～5|
|Offset / 滚动|水面 `uv + time` 一直增大|
|Shader 不用 mesh UV|用 `worldPos.xz` 当 UV，可以是几十、几百|

Mesh UV 可以是 0～1，但最终拿去采样的坐标完全可以不是。
