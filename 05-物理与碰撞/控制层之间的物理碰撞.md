最基层的规则在PhysicsSetting中，LayerCollisionMatrix可以看到每个层之间的碰撞是否开启
特殊的是单个碰撞体collider组件下的LayerOverrides和Priority属性，LayerOverrides可以覆盖掉上面的规则，直接控制与哪些层发生碰撞，哪些不发生

Layer Collision Matrix 是双向的，A 层和 B 层之间只有一个开关，两者对称。而 Layer Overrides 是单向附加在某个碰撞体上的，只影响=="这一个碰撞体"和其他层的关系，不影响同层其他碰撞体==。

Include / Exclude 的覆盖逻辑：

- `Include Layers`：全局矩阵里关闭的组合 → 强制打开（对这个碰撞体而言）
- `Exclude Layers`：全局矩阵里打开的组合 → 强制关闭（对这个碰撞体而言）
- 全局矩阵里已经打开、同时也没在 Exclude 里 → 照常碰撞

Priority 的作用场景：

两个碰撞体 A 和 B，A 的 `Include Layers` 包含了 B 所在的层，但 B 的 `Exclude Layers` 又排除了 A 所在的层，两者==矛盾==。这时候 `Layer Override Priority` ==数值大的那个碰撞体的规则获胜==。
