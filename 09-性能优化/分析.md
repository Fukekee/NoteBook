
### Profiler（性能分析器）`Ctrl+7`

最核心的工具。实时记录每帧的：

- CPU/GPU 耗时
- 内存分配
- 渲染、物理、音频、脚本各模块的开销
- 用途：找出帧率低的瓶颈在哪个系统
### Profiler (Standalone Process)

独立进程运行 Profiler，避免 Profiler 本身影响性能数据，分析结果更准确。大项目推荐用这个。

### Frame Debugger（帧调试器）

逐步回放一帧内所有 [[DrawCall]]，可以看到：

- 每个 DrawCall 渲染了什么
- 哪些被批处理合并了（SRP Batch / Static Batch）
- 用途：优化渲染顺序、排查渲染异常（穿帮、错误层级等）

### Physics Debugger（物理调试器）

可视化场景中所有碰撞体的形状、层级关系，用颜色区分不同 Layer。

- 用途：排查碰撞不触发、碰撞体位置错误等问题

在 Unity 编辑器里直接看 Android 设备的 `adb logcat` 日志，支持过滤 Tag/级别。

- 用途：真机调试 Android 版本，不用开命令行

### Code Coverage（代码覆盖率）

运行测试时统计哪些代码行被执行过，生成覆盖率报告。

- 用途：衡量单元测试的完整性

### Import Activity（导入活动）

记录资源导入历史，显示每个资源导入花了多少时间。

- 用途：排查为什么项目启动/重新导入特别慢

### Profile Analyzer（性能数据分析器）

对 Profiler 录制的数据做统计分析（均值、中位数、百分位数），支持对比两份数据。

- 用途：优化前后对比，量化性能提升效果

### Sprite Atlas Analyzer（图集分析器）

分析 Sprite Atlas 的使用情况，哪些图集被引用了、哪些没用到。

- 用途：清理冗余图集，减少包体和内存
### Performance Markers（性能标记）

查看代码中手动插入的 `ProfilerMarker` 标记数据，配合 Profiler 使用。

### Input Debugger（输入调试器）

实时显示所有输入设备状态（键盘/鼠标/触摸/手柄），新 Input System 专用。

- 用途：排查按键没响应、触摸坐标偏移等输入问题（你昨天的 UV 偏移问题也可以配合它确认触摸位置是否正确）

### Rendering Debugger（渲染调试器）

URP/HDRP 专属，可视化 GBuffer、法线、深度、光照等渲染中间数据。

- 用途：排查光照异常、材质渲染问题

### Render Graph Viewer

URP 17+ 新工具，显示渲染管线的 Render Pass 依赖图。

- 用途：优化 URP 渲染管线结构

### IMGUI Debugger

调试 Unity 旧式 `OnGUI()` 绘制的界面元素层级和调用栈。
